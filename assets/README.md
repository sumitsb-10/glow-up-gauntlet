# Photo editor images

`photo-editor-friends.jpg` is a locally bundled copy of Tim Mossholder's photo, “photography of five people near outdoor during daytime,” sourced from [Unsplash](https://unsplash.com/photos/photography-of-five-people-near-outdoor-during-daytime-hOF1bWoet_Q). It is available under the [Unsplash License](https://unsplash.com/license).

`photo-editor-friends-clean-v2.jpg` is the preview displayed after choosing **Mask the person**. It is a pre-authored blur-mask illustration, not AI object removal. `photo-editor-friends-clean.jpg` is an earlier retained preview variant. Both source and preview files are bundled so the demo works offline from `file://`.
